# Creative Workbench

Open Workbench in the header or Edit menu.

- **Adapt:** choose output sizes and per-layer scaling, anchoring, stretching or image-cover policies. Generate previews, then add independent editable frames.
- **Check:** scan contrast, clipped text, missing fonts, small interaction targets and spacing. Findings navigate to the affected frame/layer. These are heuristics, not an accessibility certification.
- **Stress test:** create copies with long, empty or supplied translated text, or cropped images. Translation is supplied by you, not an online service.
- **History:** create named checkpoints, preview and restore them. Restoration is undoable and preserves a recovery checkpoint. Save the document to persist history. Maximum 20 checkpoints and 64 MB total snapshot data.
- **Batch:** import CSV or a JSON array of flat objects; map columns to text/image layers. Image paths resolve relative to the input file. Generate previews before adding frames. Maximum 100 rows, 4 MB input, 32 MB per image.
- **Deliver:** export an offline ZIP containing the native project, frame PNG/SVG exports, original images, prototype flows, checks and design notes. Fonts are referenced, not redistributed. Prototype HTML includes reachable flow screens; exports include all frames.

Generated frames are copies, not live-linked responsive variants. Backend publishing and AI remain deferred.
